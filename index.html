# LocalAI Architecture Overview LocalAI acts as a drop-in replacement REST API that is compatible with OpenAI API specifications for local inferencing. It uses C++ and Go bindings to interface directly with backends: - llama.cpp (LLMs, GGUF models) - vLLM (High-throughput token generation) - whisper.cpp (Speech-to-text transcription) - stable-diffusion.cpp (Image generation) - audio.cpp (Voice recognition, VAD, diarization) All model weights stay local. No external calls, telemetry, or API keys required.

# Getting Started with LocalAI LocalAI is an OpenAI-compatible API running locally on CPU or GPU. You can run any GGUF or ONNX model without needing specialized drivers. Core Endpoints: - POST /v1/chat/completions : Chat with Llama, Mistral, Gemma, Phi models - POST /v1/embeddings : Generate vector embeddings for RAG - POST /v1/audio/transcriptions : Transcribe audio files via whisper.cpp - POST /v1/images/generations : Generate images via stable-diffusion.cpp To start LocalAI: $ docker run -p 8080:8080 localai/localai:latest
